# Alcance del Sistema

El sistema abarcará las siguientes funcionalidades y módulos para la operación del punto de venta:

- **Autenticación y Seguridad:**
  - Login de empleados mediante credenciales únicas (usuario y contraseña).
  - Control de accesos y permisos según el rol asignado.

- **Gestión de Usuarios y Roles:**
  - Módulo administrativo para altas, bajas (lógicas) y modificaciones de usuarios y asignación de roles.

- **Operación en Punto de Venta (Caja):**
  - Registro ágil de ventas mediante lector de código de barras o búsqueda manual por nombre de producto.
  - Registro del medio de pago utilizado por transacción.
  - Corrección de errores en compras en proceso mediante intervención del supervisor de caja.
  - Emisión y generación de tickets de compra.

- **Gestión de Inventario y Catálogo:**
  - Administración completa de productos y categorías (altas, modificaciones y bajas lógicas).
  - Control de stock y actualización de precios.
  - Descuento automático del stock una vez confirmada y concretada cada venta.

- **Gestión de Clientes:**
  - Registro y vinculación de clientes dentro del flujo del sistema.
